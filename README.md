# YAiPlayer

IPTV-плеер: Android TV, Android телефон/планшет, Web. Свои плейлисты M3U/M3U8, Stalker/Ministra, Xtream, EPG.
Встроенного контента нет.

- `clients/android-tv`, `clients/android-mobile`, `clients/owntv-core` — Android (GPL-3.0, см. LICENSE в каждой папке)
- `clients/web` — Web-клиент (PolyForm Noncommercial 1.0.0, см. clients/web/LICENSE и NOTICE)

## Релизы и загрузка
- Репозиторий: https://github.com/eai-apps/YAiPlayer
- Свежие выпуски: [Последний релиз](https://github.com/eai-apps/YAiPlayer/releases/latest)
  - `YAiPlayer-Mobile.apk` — для телефонов и планшетов
  - `YAiPlayer-TV.apk` — для Android TV

Сборка: GitHub → Actions → Build. Подробности для помощников — HANDOFF.md.
