# Автопост релизов в Telegram

Каждый релиз (`.github/workflows/release.yml`, шаг «Post to Telegram channel») публикуется в канал:
версия, «что нового» и прямые ссылки на APK (TV и телефон).

- Текст «что нового» берётся из `docs/WHATS_NEW.md` (по-русски, пункты `- ...`). Перед каждым изменением
  для пользователей дописывайте туда пункт; после релиза файл очищается автоматически.
- Секреты репозитория (Settings → Secrets and variables → Actions): `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`
  (для публичного канала — `@YAiPlayer`). Бот должен быть администратором канала с правом публикации.
  Без секретов шаг просто пропускается.
- Сами APK не отправляются файлом: Bot API принимает файлы до 50 МБ, а APK ~58 МБ. Вместо этого — прямые ссылки.
- Проверка текста без отправки: `python3 telegram-release/post_release.py --release-json release.json --dry-run`.
- Тесты: `python3 -m unittest telegram-release/test_post_release.py`.

## Ежедневный дайджест (`daily_digest.py`, workflow `daily-digest.yml`)
Один пост в 09:00 по Берлину о релизах с 09:00 предыдущего дня; в тексте без слов «за сутки»: «Вышли новые версии, сейчас актуальная …». Формат (rich-сообщение): картинка-шапка `brand/telegram-banner-1280x720.png`, краткое резюме суток, таблица версий, блоки «Новое» и «Исправлено» (тема жирным, суть курсивом, ОДНА строка на тему), мелочь в раскрывающемся блоке, кнопки «Скачать» и «Написать в чат». Скрытые функции (список `SKIP` в скрипте) не анонсируются. Если Telegram не принял rich, уходит тот же текст обычным сообщением. Тесты: `python3 -m unittest telegram-release/test_daily_digest.py`.
Заголовок поста меняется каждый день (`HOOKS`, 30 вариантов). Правила от владельца: см. раздел «Дайджест в Telegram» в корневом HANDOFF.md.

## Пост про поддержку (`post_support.py`, workflow `support-post.yml`)
Раз в 3 дня около 12:00 по Берлину: как сообщить об ошибке или попросить функцию, какие данные указать (устройство, приложение и версия, оператор или Stalker, проверка в других плеерах, скриншот, лог) и как снять журнал (ТВ: Настройки → Журнал ошибок → Экспорт журнала → QR; телефон: Настройки → Приложение → Экспорт журнала → Поделиться). Три заголовка по очереди. Постер `brand/support-poster-1280x720.png`. Ручной запуск: Actions → Support post to Telegram → Run workflow. Тест: `python3 -m unittest telegram-release/test_post_support.py`.
