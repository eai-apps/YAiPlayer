# Задание 2 для Codex: ядро телепрограммы (порядок источников, главная без ожидания, докачка Stalker)

Ветка `test/epg-core` от свежего `origin/main` (после слияния задания 1; если main ещё без него, брать от своей ветки задания 1 и сказать об этом в отчёте). Это ядро: Claude/Opus проверит в среду, поэтому пиши аккуратно, с тестами, маленькими коммитами и подробным описанием в `HANDOFF.md`.

Источник требований: `docs/CHECKLIST.md`, раздел «3. Opus, среда вечером» пункты 1–3. Кратко:
1. **Порядок EPG.** Сначала адрес телепрограммы из самого плейлиста (`url-tvg`). Потом проверка, у каких каналов программы нет. Только для них по очереди встроенные источники (встроенные не называть в интерфейсе и релизных записях). Плейлист без своего адреса сразу использует встроенные. Архив (прошедшая программа) тоже. Ручные привязки EPG и приоритет пользовательских источников сохраняются. Найди реализацию в `EpgSyncWorker`, `BuiltinGuide`, `EpgRepository`, `epgSourceStore.priority()`; поведение сейчас может отличаться, сперва опиши в `HANDOFF.md`, как оно устроено сейчас, потом измени.
2. **Главная не ждёт EPG.** Плитки главного экрана появляются сразу, телепрограмма грузится в фоне. Убрать тормоза меню после пересинхронизации (сейчас меню и список подвисают на несколько секунд, когда идёт запись EPG в базу: проверь размеры транзакций, `chunked`, индексы, `Dispatchers`, и что UI не ждёт завершения синхронизации). Добавь метки времени в `CorePerf.log`.
3. **Докачка Stalker по понедельникам.** Оператор обновляет свой список в понедельник около 18–21. Расписание: понедельник в 9, 12, 15, 18, 21 и контрольная во вторник в 9 (WorkManager, без нажатия пользователя, только при Wi-Fi/любой сети и не при низкой батарее; можно отключить в настройках EPG). В каждый запуск смотреть, у каких каналов нет программы на ближайшие сутки, и докачать её с резервных источников; не трогать каналы, у которых программа есть. Пустые результаты не повторять в тот же запуск.

## Готово, когда
Build и Tests зелёные, тесты на порядок источников, на «только для каналов без программы», на расписание. `HANDOFF.md`: подробно что изменено и риски. WHATS_NEW: пользовательские пункты (без названий источников).
