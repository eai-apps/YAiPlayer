## A. Пульт с телефона (проверить и довести)
Цель: управлять ТВ-приставкой по домашнему Wi-Fi без регистрации: кнопки пульта, «отправить на ТВ» (ссылка/канал), клавиатура с телефона. Кнопка на стартовом экране телефона рядом с выбором профиля/гостя.
Старая ветка `origin/test/remote` не собиралась (~45 ошибок из-за выдуманных API); можно брать из неё только идеи. Реальные API смотри в исходниках.
**Безопасность (обязательно, это главное):**
- Привязка телефона к ТВ: код/PIN или QR на экране ТВ, одноразовый, срок короткий; после привязки токен хранится на обоих устройствах (на ТВ только в хэшированном виде); можно отвязать устройство на ТВ.
- Порт слушает только в локальной сети, без привязки ничего не принимает; команды только с подписью токена; ограничение частоты попыток подбора PIN; никаких данных профиля, источников и паролей через пульт не передавать.
- Включается явным переключателем на ТВ (по умолчанию выключено) с понятным текстом.
- Ввод с телефонной клавиатуры только в активное поле ТВ.
Тесты: привязка, неверный токен, повторное использование кода, отвязка. Паритет: приёмник на ТВ-приложении, клиент в мобильном.

## B. «Ускорь телевизор» (мастер + настоящий ADB)
По мотивам Gathin23/cleanyourtv (MIT). Список пакетов и пояснения: `docs/TV_OPTIMIZER_DATA.md`. Только телефон. Если мастер Антигравити (`test/tv-optimizer-ui`, уже в main) только заглушка, реализуй настоящий ADB-клиент:
- Подключение телефона к ТВ по Wi-Fi ADB (порт 5555) через Android-библиотеку ADB (например `dadb` или аналог под лицензией, совместимой с GPL; проверь лицензию и запиши в `docs/THIRD_PARTY.md`), с запросом авторизации на ТВ (RSA-ключ хранится на телефоне).
- Только `pm disable-user --user 0 <пакет>` (не удаление), с сохранением списка отключённых пакетов, кнопкой «вернуть всё» и «вернуть один».
- Защитный список: никогда не отключать лаунчер, сервисы Google Play, наше приложение, системные пакеты из чёрного списка. Показывать пользователю список и пояснение к каждому пакету, галочки по умолчанию только у безопасных.
- Предупреждение «на свой страх и риск» только перед применением.
- Пошаговая инструкция «как включить отладку по сети» на русском для типовых приставок.
Тесты: разбор списка пакетов, защитный список, откат, формирование команд (без реального ADB).
Лицензия MIT сохраняется для скопированных данных: текст лицензии и авторство upstream в `docs/THIRD_PARTY.md`. Не подтягивать upstream автоматически.
