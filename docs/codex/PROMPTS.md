# Готовые промпты для Codex (одно задание = один новый чат)

Каждый промпт вставляется в НОВЫЙ чат Codex. Задание заканчивается итоговым отчётом Codex; тогда владелец сообщает об этом Claude, и Claude проверяет ветку.

Общая часть (есть в каждом промпте): репозиторий eai-apps/YAiPlayer, прочитать docs/codex/README.md, не пушить в main, ветка от свежего origin/main, push без force, дождаться зелёных Build и Tests, отчёт только по проверенному, по-русски в мужском роде, после отчёта остановиться.
