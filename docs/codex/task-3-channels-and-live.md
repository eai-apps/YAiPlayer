# Задание 3 для Codex: каналы и живой эфир

Ветка `test/channels-live` от свежего `origin/main`. Прочитай `docs/codex/README.md`.

## A. Перенос канала между категориями и «Только с архивом»
- Перенос канала (не копия, копирование в свои категории уже есть): канал убирается из старой категории и показывается в новой; перенос не возвращается назад после обновления плейлиста (хранить как пользовательскую правку по id канала/источника, учитывать при пересинхронизации). Меню: удержание OK на ТВ, долгое нажатие на телефоне.
- Переключатель «Только с архивом» в списке каналов (ТВ и телефон): показывает только каналы с архивом (признак есть в данных: tv_archive/catchup, смотри `ChannelEntity`). Состояние помнится на профиль.

## B. Живой эфир: диагностика и повторы
Из `docs/CHECKLIST.md`, раздел 6з: подробный лог запросов к серверу (заголовки, статус, строка «канал у провайдера недоступен: 404/504», чтобы отличать «канал лежит у провайдера» от «ошибка нашего плеера»), один повтор запроса ExoPlayer при 5xx перед уходом на mpv, не держать два соединения (превью + полный экран), не запрашивать поток сразу после остановки архива. `OPEN_TIMEOUT_MS = 12_000` (`LiveExoWatchdog`) не менять без доказательства из лога. Уже сделано в v3.0.31: нужно 2 сбоя для перехода на mpv, 404/410/5xx не считаются виной ExoPlayer (`LiveStreamQuirks`).

## C. Выход из плеера в меню (тормоз и чёрный экран ~5 с)
Если Антигравити уже добавил метки в лог (ветка `test/list-epg`), прочитай их код и дополни: что останавливается и в каком порядке при «Назад» (Exo, mpv, превью, архив, таймеры), где блокируется главный поток. Если причина очевидна, исправь отдельным коммитом, иначе только метки и описание в `HANDOFF.md`.

## D. Аудит SettingsTransferServer
Только отчёт и мелкие безопасные исправления: что слушает порт, кто может подключиться по локальной сети, есть ли токен/PIN, что передаётся, русские тексты без смешения языков, локализация. Результат запиши в `HANDOFF.md` (раздел «Аудит SettingsTransferServer»). Крупные изменения не делай, предложи.
