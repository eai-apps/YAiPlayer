# Формат данных TvOptimizer (TV_OPTIMIZER_DATA)

Пакеты и профили оптимизации для телевизоров хранятся в формате JSON в каталоге `assets/tvoptimizer/` (по умолчанию `demo.json`).

## Структура файла

```json
{
  "models": [
    {
      "id": "model_id",
      "name": "Название модели телевизора"
    }
  ],
  "packages": [
    {
      "package": "com.example.app",
      "titleKey": "string_resource_key_for_title",
      "descriptionKey": "string_resource_key_for_description",
      "risk": "safe | moderate | high",
      "recommended": true,
      "models": ["model_id_1", "model_id_2"]
    }
  ]
}
```

## Поля

### `models`
Список поддерживаемых семейств ТВ:
- `id` (строка): уникальный идентификатор модели/семейства (например, `xiaomi_mitv`, `sony_bravia`, `android_tv_generic`).
- `name` (строка): отображаемое название для пользователя в мастере.

### `packages`
Список пакетов приложений для отключения:
- `package` (строка): имя Android-пакета (`applicationId`), например `com.google.android.youtube.tvunplugged`.
- `titleKey` (строка): ключ строкового ресурса с понятным названием приложения.
- `descriptionKey` (строка): ключ строкового ресурса с описанием («Что это такое и зачем отключать»).
- `risk` (строка): степень риска:
  - `safe` — абсолютно безопасно для работы телевизора, сторонние или сервисные приложения.
  - `moderate` — приложение вендора (лаунчер, магазин производителя, обновление компонентов).
  - `high` — системные службы (требуется повышенная осторожность).
- `recommended` (boolean): `true`, если пакет рекомендуется к отключению по умолчанию кнопкой «Выбрать рекомендуемое».
- `models` (массив строк, опционально): список идентификаторов моделей, к которым применим данный пакет. Если отсутствует, пакет считается универсальным.
