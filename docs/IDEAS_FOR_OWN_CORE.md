# Идеи для собственного ядра (БЕЗ копирования кода)

Цель: свой плеер (Android TV → iPhone/Apple TV) со своей закрытой лицензией. Из GPL-кода OwnTV сюда ничего не копируется — только идеи, сценарии и форматы протоколов (протоколы Stalker/Xtream/M3U/XMLTV публичны).

## Сценарии, которые полезны пользователю
- Источники без профиля: любое число плейлистов M3U, Xtream, Stalker и ссылок EPG; «гостевой» режим; форма не теряет ввод при ошибке и показывает, на каком шаге отказ (handshake / вход / профиль) с текстом ответа портала.
- Быстрый доступ «Мои источники» с главного экрана.
- Stalker: вход по логину/паролю без MAC; генерация MAC; серийный номер и Device ID вычисляются по MAC (повторяемо), можно задать вручную; выбор модели MAG.
- Канал открывается сразу на весь экран; предпросмотр со звуком — настройка.
- Синхронизация источников/избранного между телефоном и приставкой через облачный аккаунт; привязка ТВ по PIN/QR.
- Обновление приложения изнутри (GitHub Releases, универсальная ссылка без версии).

## Модули, которые можно писать независимо и проверять тестами
M3U-парсер, XMLTV-парсер, клиент Xtream, клиент Stalker, хранилище (база), слой синхронизации, обновление.

## Монетизация (идеи)
Бесплатно: базовое воспроизведение, ограниченное число источников. Платно: облачная синхронизация, безлимитные источники, запись/таймшифт, мультиэкран, темы, родительский контроль, резервные копии. Включение функций — флаги на сервере (админка).
