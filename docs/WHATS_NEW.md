- «Лёгкий режим»: специальный переключатель оптимизации для слабых устройств, отключающий видео-превью в меню и снижающий анимации интерфейса для максимальной плавности.
- «Ускорь телевизор»: мастер на телефоне для безопасного отключения лишних предустановленных приложений на Android TV без удаления, с автосохранением и возможностью отката.
- Заставка по умолчанию выключена; включить и настроить время можно в Настройки → Приложение → Заставка.
