- Несколько источников телепрограммы (EPG) для одного плейлиста: при добавлении или редактировании плейлиста на ТВ и телефоне теперь можно указать несколько адресов EPG. Порядок в списке задаёт приоритет — программа берётся в первую очередь из верхнего источника, а недостающие передачи дополняются из следующих.
- Экспорт журнала диагностики: в «Журнале ошибок» появилась кнопка «Экспорт журнала», которая формирует полный текстовый отчёт для поддержки. На ТВ поднимается локальный сервер с адресом и QR-кодом для быстрого скачивания на телефон или ноутбук по домашней сети, а на телефоне открывается стандартное меню «Поделиться». Все пароли, токены и адреса провайдеров надёжно маскируются.
