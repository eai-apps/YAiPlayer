<!-- Пункты для пользователя, по-русски. -->
- Пульт с телефона без регистрации: кнопки, тачпад, громкость и переключение каналов по домашней сети; приём на ТВ включается отдельно в настройках.
- Привязка по одноразовому коду и отпечатку сертификата ТВ; доступ телефона можно отозвать на телевизоре.
- Ввод с телефона в активное поле ТВ, отправка текущего канала по названию и публичной ссылки на видео без паролей.
