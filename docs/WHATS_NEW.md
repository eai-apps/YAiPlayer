- «Ускорь телевизор»: мастер на телефоне для безопасного отключения лишних предустановленных приложений на Android TV без удаления, с автосохранением и возможностью отката.
- Экранная заставка для ТВ: плавные фото природы и космоса (NASA, Wikimedia), постеры каталога, часы со смещением против выгорания, автоматическое включение при простое и на паузе, продолжение воспроизведения по кнопке Play.
- Быстрое скрытие категорий (страны, спорт, взрослые и другие) прямо из меню плейлиста, на ТВ и на телефоне.
- Смещение программы передач по времени: если телевизионная программа у провайдера сдвинута, её можно поправить вручную для каждого плейлиста.
- «Вчера в эфире»: быстрый переход к вчерашним передачам канала из архива.
- Подключение Stalker-порталов: поддержка MAC-адреса в разных форматах и новые пункты в подменю управления источниками.
