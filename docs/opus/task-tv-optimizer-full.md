## Сделать (порядок)
1. Причина пустого списка (скрин + «Экспорт журнала» с телефона). Три группы приставки: «новый главный экран + очистка» / «только очистка» / «невозможно»; неизвестная модель — осторожная очистка по бренду (консенсус).
2. «Показать все команды» до запуска; ручной выбор дополнительных пунктов.
3. Ускорение самой приставки: масштабы анимаций (window/transition/animator 0.5/0), лимит фоновых процессов — с откатом к прежним значениям.
4. В конце выключать сетевую отладку (если не попросили оставить).
5. Лаунчер целиком: панель любимых, порядок, библиотека приложений, 29 тем (config.json), свои обои с телефона (1280×720, <300 КБ, смена по минутам), строка CPU/память, reduced_motion, кнопки Input/YouTube/⚙ после замены лаунчера, модули-плитки.
6. Частный DNS (AdGuard) — с предупреждением: рекламу YouTube не убирает, резолвер видит запросы.
7. После прошивки: «что вернулось» + «выключить снова».
8. Замеры до/после: отклик, запуск, нагрузка в простое.
9. Отчёты «Помогите добавить приставку» / «Сообщить о проблеме» без адресов/серийников, ничего не отправляют сами.
