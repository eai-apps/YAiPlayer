# «Ускорь телевизор»: проверка на приставке (для владельца)

Плитка «Ускорь телевизор» на экране профилей включается для всех только после этой проверки и слова владельца. До этого мастер открывается из пульта: он есть и в обычной сборке.

Что нужно: телефон с YAiPlayer (последняя версия), приставка Panasonic в той же сети Wi-Fi, 15 минут.

## 1. Включить на приставке отладку по сети (один раз)
1. На приставке: **Настройки** (шестерёнка справа вверху) → **Настройки устройства** → **Об устройстве**.
2. Пролистать до строки **Сборка** и нажать на неё **7 раз** кнопкой ОК пульта. Появится «Вы стали разработчиком».
3. Назад → **Настройки устройства** → **Для разработчиков**.
4. Включить **Отладка по USB** (на части приставок называется «Отладка ADB»). Если есть пункт **Отладка по Wi-Fi / по сети**, включить и его.
5. Запомнить IP-адрес приставки: **Настройки** → **Сеть и Интернет** → ваша сеть Wi-Fi → строка **IP-адрес** (например 192.168.1.50).

## 2. Открыть мастер на телефоне
1. Телефон: YAiPlayer → экран профилей → плитка **Пульт ДУ**.
2. Вверху выбрано **Вся приставка**. Под пультом кнопка **Ускорить ТВ** → нажать.
3. В мастере пройти шаги до **Подключение к ТВ**, ввести IP приставки → **Подключиться**.
4. На **экране телевизора** появится окно «Разрешить отладку?» → отметить **Всегда разрешать с этого компьютера** → **ОК**.

## 3. Что проверить (отметьте да / нет)
| № | Шаг | Ожидаем |
|---|---|---|
| 1 | После подключения | Строка «Подключено: Panasonic … · Android …» |
| 2 | **Выбрать модель из списка** или **Осторожно по бренду** | Список приложений с пометками риска; системные (клавиатура, Wi-Fi, пульт, Play) недоступны для отключения |
| 3 | Отметить 2–3 приложения с пометкой «безопасно», галочка «Я понимаю и беру ответственность на себя» → **Отключить выбранное (N)** | Прогресс по каждому, в итоге список отключённых |
| 4 | На приставке открыть главный экран | Отключённых приложений нет в списке, приставка работает |
| 5 | В мастере **Управление и откат** → **Вернуть всё как было** | Все отключённые приложения снова на приставке |
| 6 | Повторить шаг 3, затем **закрыть YAiPlayer на телефоне** и открыть снова → **Управление и откат** | Точка восстановления сохранилась, «Вернуть всё как было» работает |
| 7 | (по желанию) **Новый главный экран**, на вопрос телефона не отвечать | Через 150 секунд приставка сама возвращает свой главный экран («Прежний главный экран вернулся») |
| 8 | В конце: **Выключить отладку на ТВ** | Связь с ТВ закрывается, отладка на приставке выключена |

Если что-то не так: в мастере **Управление и откат** → **Сохранить копию (скрипт для компьютера)**: там команды, которыми всё возвращается с компьютера. Напишите, на каком шаге и что видно на экране.

## После проверки
Скажите «включай плитку» — тогда `TV_OPTIMIZER_READY` станет `true` и плитка появится у всех в следующем выпуске.

Автоматически проверено тестами (без приставки): защита системных приложений, точка восстановления до первого изменения, восстановление после перезапуска, откат всех приложений и главного экрана (`TvOptimizerTest`, 14 тестов).
