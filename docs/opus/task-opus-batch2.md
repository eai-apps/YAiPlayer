Автор задания: Claude Sonnet 5.5, по сообщению и 20 фото владельца (приставка Panasonic, телефон). Владелец проверил выпуск v3.0.42 и считает его неудачным: приставка тормозит, радио некрасивое, пульт не находит приставку. Код в этом задании НЕ менялся — всё ниже делает Opus.

Правила (как всегда): ветка от свежего `origin/main` (`test/opus-fix-1112`), `git pull --rebase` перед push, без force-push, секреты не просить, слияние в main только при зелёных Build и Tests; отвечать владельцу по-русски, по шагам, с полным путём кликов, о себе в мужском роде. Пуш в main = выпуск, поэтому влейте всё одним готовым пакетом. Сборка ОДНА (с радио, самообновление по прежней ссылке). Название магазина нигде не писать. Паритет ТВ и телефона везде, где применимо. Новые строки — через i18n-реестр (en/ru/de).

## Приоритет 1 — скорость и нагрузка (самое важное: приставку «выбивает»)
Наблюдения по фото ТВ: плашка «Обновление… 2 из 2 · Обновление программы передач · эдем · 979 каналов · 222 тыс. записей EPG» висит на экране 10+ минут; счётчик растёт (103 тыс. → 148 → 156 → 225 → 257 тыс.), пока всё лагает, картинки и значки долго не подгружаются, приставка несколько раз перезагружалась (вероятно, нехватка памяти). Плашка к тому же налезает на содержимое (названия карточек сериалов, нижние строки списков).
Что владелец хочет:
1. **Отменить автообновление при каждом запуске/входе в профиль.** Никаких `staleCatchUp` при старте приложения, при входе в профиль, при выходе из паузы. Любая загрузка портала/плейлиста/EPG — только по расписанию или вручную.
2. **Расписание (решение владельца):** обновление портала/плейлиста/EPG по **понедельникам в 09:00, 15:00 и 19:00 и по вторникам в 09:00**. Если в понедельник/вторник приставка не включалась — обновить при первом запуске после (среда, четверг и т. д.), но один раз за неделю и по той же очереди. Раз в неделю достаточно. Реализация: WorkManager/проверка «последнее успешное обновление» по каждому источнику + «окно недели» (понедельник 00:00 Europe/Berlin по времени устройства). Не обновлять источник, который уже обновлён в эту неделю. Прикинуть, как совместить с `owner-answers-1112` (фон только на зарядке на телефоне).
3. **Ручное «принудительно обновить»** (Настройки → Синхронизация → «Синхронизировать всё» / «Только телеканалы» / «Только телепрограмму» / «Каналы и телепрограмма» / «Фильмы и сериалы», и «Обновить портал» в быстрых действиях) должно **сразу показывать, что запущено**: плашка с названием шага и реальным прогрессом, а при уже идущем обновлении — понятное сообщение «Обновление уже идёт, шаг N из M». Сейчас владелец нажимает — ничего не видно, непонятно, началось ли. Должна быть кнопка «Отмена» у идущего обновления.
4. **Нагрузка EPG:** разбор в фоновом потоке с низким приоритетом, пакетные записи в БД (транзакциями), потоковый разбор без загрузки всего файла в память, ограничение числа параллельных запросов, не качать EPG для скрытых категорий (см. П5б ниже), не держать плашку на экране поверх контента (компактный индикатор в углу/в шапке, не перекрывает карточки). Цель: на слабой приставке (Panasonic, Android TV) интерфейс не лагает во время обновления, а первое обновление 5–6 тыс. каналов укладывается в разумное время. Замерить и записать цифры в HANDOFF.
5. **Аудит ядра и производительности:** запуск приложения (холодный старт), лишние перекомпозиции Compose в списках каналов/сериалов, загрузка картинок (размеры, кэш, отмена при прокрутке, не декодировать больше размера плитки), утечки памяти, OOM-перезагрузки приставки. Поставить Coil/загрузчик на лимит памяти для low-RAM устройств. Убрать, что без пользы работает на старте.
6. **Пустой профиль на телефоне:** владелец открыл профиль без плейлиста и без Stalker — приложение всё равно начало грузить «какой-то плейлист/EPG» и **грузит бесконечно** (видно в шторке уведомлений). Исправить: профиль без источников ничего не загружает и не показывает прогресс; при ошибке/отсутствии источника цикл повторов не крутится; уведомление/foreground не должно висеть. Проверить и ТВ.

## Приоритет 2 — пульт не находит приставку (телефон)
Телефон: Меню → Пульт ДУ → пишет, что телефон «находится в другой сети», хотя это та же Wi-Fi сеть. Других возможностей на экране нет.
Сделать: не блокировать по определению «другой сети» (искать причину: сравнение подсети, VPN/частный DNS на телефоне, двойной NAT/гостевая сеть, Wi-Fi-расширитель, отсутствие `CHANGE_WIFI_MULTICAST_STATE`/MulticastLock, нет разрешения NEARBY_WIFI_DEVICES/локации на Android 13+). Поиск `_androidtvremote2._tcp` запускать при любой доступной сети, показывать список найденных; добавить **ручной ввод IP-адреса приставки** (и подсказку, где его посмотреть: Настройки ТВ → Сеть); добавить экран диагностики («Wi-Fi: да, адрес: …, найдено устройств: 0, что проверить»). Также выполнить доработки пульта из списка «НЕ сделано» ниже. Проверить, что включена «Отладка по USB» не требуется для пульта (только для «Ускорь телевизор»).

## Приоритет 3 — радио: переделать дизайн (ТВ и телефон)
Скриншоты радио на ТВ: чёрный экран без оформления; список жанров слева сырой (`popular`, `pop`, `russian_rock`, `kannadahits` …); при прокрутке вниз верхние жанры и значки «чернеют»/пропадают, фон некрасивый; кнопки «пауза / Стоп / сердце» в правом верхнем углу — неудобно и непрофессионально. То же на телефоне. Эталон — сайт YAiPlay Radio (там цветные плитки жанров, мини-плеер внизу).
Сделать:
1. **Жанры как на сайте:** цветные плитки с красивыми названиями (русские подписи через таблицу соответствия, тех. ключи не показывать), сетка. Категорию `russian_rock` **скрыть** (владелец: не нужна). Незнакомые тех. ключи (`kannadahits` и т. п.) не выводить сырыми — прятать или человекочитаемо.
2. **Мини-плеер внизу** (как на сайте): обложка, название станции, ICY-трек, play/пауза, стоп, избранное (сердце), громкость где уместно; не в правом верхнем углу. Развернуть до полноэкранного режима: большая обложка станции, анимация (волны/эквалайзер, лёгкая и отключаемая в лёгком режиме), крупные кнопки. D-pad на ТВ: фокус всегда видим, ничего не пропадает при прокрутке (проверить фокус-модификаторы, перекомпозиции и фон при прокрутке — именно там чернеют верхние строки).
3. **Фон — в цветах плеера** (тот же градиент/тема, что у остального приложения), без чёрных пятен; логотипы станций с плейсхолдером (у части станций значков нет — рисовать красивую заглушку с первой буквой).
4. «Избранное», «Подборки», «Аккаунт и синхронизация» — оставить, оформить тем же стилем; добавление в избранное одной кнопкой, избранное обменивается с сайтом.
5. Тестировать на слабом железе: прокрутка сетки станций без лагов, ленивая подгрузка значков.

## Приоритет 5 — страница сериала и список сериалов (ТВ, паритет — телефон)

1. **Американская история ужасов [S13]:** постер сдвинут вправо от центра и **накладывается на кнопки «Сетка / Список» и сортировку «Сначала старые»** (на двух фото крупным планом). 2. **Не подтянулись все сезоны:** выпадающий список «Сезоны» показывает 1, 2, 3, 4, 9, 12, 13 (пропущены 5–8, 10, 11), шапка пишет «7 сезонов». Причина — сезоны оформлены отдельными карточками портала `[S05]…`; нужна сборка всех сезонов сериала из всех карточек портала (см. склейку ниже), а не только из той, на которую нажали. Не терять сезоны при разных тегах `[ua] [ru]`, регистре, пробелах.
3. **Склейка карточек «Извне / Ззовні [S01]…[S04]» (П8):** в списке «Сериалы» одна карточка на сериал (название без `[S01] [ua] [ru]`), внутри — выбор «Сезон N» со всеми сезонами и серии каждого. Сейчас в списке 4–5 отдельных карточек, и в каждой внутри виден весь набор сезонов — дубль. Группировать по нормализованному названию (до тега сезона) + учитывать язык-теги; постер — с первого/выбранного сезона; «Продолжить» — по сохранённому прогрессу. Заголовок на странице без технических скобок. Паритет на телефоне.
4. Плашка прогресса не должна накрывать карточки сериалов (см. приоритет 1).
