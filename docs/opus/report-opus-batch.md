## Что подтверждено тестами (без устройства)
- Протокол пульта: кодирование/разбор protobuf polo и remotemessage, формула секрета сопряжения, полный обмен по TLS с поддельным «телевизором» на loopback, отказ при чужом сертификате.
- Оптимизатор: выбор пакетов по модели/бренду, защитный список (лаунчер, сервисы Google, наш плеер), формирование команд `pm disable-user`/`pm enable`, точка восстановления, сторожевой откат лаунчера.
- Очередь обновлений: порядок «портал активного профиля → его EPG → остальные EPG по одному», чужие профили не качаются при старте, отбор «обновлялось не сегодня».
- Сезоны: разбор «[S01]…[S13]», сортировка, число сезонов из реального набора.
- Радио: разбор каталога и Radio Browser, правило синхронизации сайта (новее побеждает, первое слияние без потерь, треки и плейлисты сайта не затираются), правило логина как у сервера.
- Play-сборка: в dex нет классов радио, нет строк `radio_*`, нет `REQUEST_INSTALL_PACKAGES`; в full всё это есть (контрольная проверка).
- i18n: новые строки en/ru/de, сканер включает `src/full` и `src/play`; базовые списки не выросли.

## Что проверяется только на приставке/телефоне
1. **Пульт:** телефон находит приставку в Wi-Fi, код с экрана ТВ, D-pad/Домой/громкость/ввод текста, повторное подключение без кода, вторая приставка в списке.
2. **Ускорь телевизор** (только debug-сборка, `TV_OPTIMIZER_READY = BuildConfig.DEBUG`): отладка по сети на ТВ, подключение, список по модели, «Применить» → «Откатить», установка и снятие лаунчера, автоматический возврат домашнего экрана через 150 с.
3. **Очередь при старте:** после обновления приложения одно сводное кольцо «Обновление… 1 из N» вместо четырёх; время EPG для 4,5–6 тыс. каналов (в журнале строка с замером по этапам), честный процент.
4. **Логотипы:** у каналов без логотипа подставляется логотип из EPG-источника.
5. **Страница сериала на ТВ:** постер ничего не перекрывает, «Продолжить» не налезает на сезоны, «Сезон N ▾» открывает все сезоны (13+), серии сеткой, «Серии ▾» при 30+, пульт доходит до всех элементов. Телефон: выпадающий выбор сезона, обложки фильма/сериала не растянуты.
6. **Радио:** пункт над «Телеканалами», плитка на экране профилей ТВ и телефона, «Назад», вход в аккаунт YAiPlay Radio и обмен избранным с сайтом; Play-сборка без радио и без «Проверить обновления».
