# Задачи для Antigravity («Integrity»)

Общие правила: репозиторий eai-apps/YAiPlayer, работаем в ветке `test/<имя>`, TV и телефон делаем одинаково, все тексты — через строковые ресурсы (values + values-ru), классификацию литералов i18n не ломать (`verifyI18nLiterals`), в `docs/WHATS_NEW.md` — только русские пункты для пользователя. Секреты не трогать и не запрашивать.

## Задача A. Несколько источников EPG при первой настройке плейлиста

Сейчас в мастере добавления плейлиста можно указать один адрес EPG. Нужно:

1. В мастере (TV: первая настройка и «Добавить плейлист»; телефон: те же экраны) заменить одно поле «Адрес EPG» на список: кнопка «Добавить источник EPG», у каждой строки — поле адреса, кнопка «Удалить», порядок = приоритет (первый главнее; сверху вниз).
2. Хранение: найти, где сейчас сохраняется адрес EPG плейлиста (Room/DataStore), и расширить до списка без потери старых данных (миграция: старый одиночный адрес становится первым пунктом списка).
3. Загрузка: `EpgRepository` должен грузить все источники плейлиста; пересекающиеся программы разрешает существующий `GuidePriority` (приоритет по порядку в списке).
4. Валидация: пустые строки отбрасывать, дубли убирать, адрес должен начинаться с http/https; ошибка — подпись под полем.
5. Тесты: миграция, порядок приоритета, парсинг списка.
6. Управление с пульта: список полностью управляется D-pad (фокус на строках и кнопках), как остальные экраны мастера.

Критерий готовности: можно добавить 2–3 адреса EPG при добавлении плейлиста, программа подтягивается из всех, старые плейлисты работают как раньше.

## Задача B. Экспорт журнала (TXT) на телефон/ноутбук/Telegram

Нужна простая выгрузка полного журнала диагностики одним файлом `.txt`:

1. Кнопка «Экспорт журнала» в Настройки → Диагностика (TV и телефон). Формирует `yaiplayer-log-YYYYMMDD-HHmm.txt`: версия приложения, устройство/Android, активные источники (без адресов, логинов и паролей — всё маскировать), трассировка `GuideTrace`, журнал воспроизведения `PlaybackErrorLog`, последние ошибки.
2. Способы передачи:
   - **По домашней сети (основной, на TV):** приложение поднимает на время экспорта маленький HTTP-сервер на случайном порту, показывает на экране адрес вида `http://192.168.x.x:PORT/log.txt` и QR-код. Пользователь открывает адрес в браузере телефона/ноутбука в той же Wi-Fi сети и скачивает файл. Сервер сам выключается через 5 минут или по кнопке «Остановить». Одноразовый случайный токен в адресе. Только локальная сеть.
   - **На телефоне:** системное меню «Поделиться» (Telegram, почта, Файлы) через `FileProvider`.
   - **Bluetooth:** отдельным вторым этапом, только если получится стабильно (на TV часто нет OBEX-отправки); без него задача считается выполненной.
3. Тесты: маскирование секретов (адреса, логины, пароли, токены не должны попадать в файл), формирование имени файла.
4. Никаких отправок в интернет автоматически — только по действию пользователя.

Критерий готовности: на TV открывается экран с адресом и QR, файл скачивается на телефон, секретов в нём нет.
