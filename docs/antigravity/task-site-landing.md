# Задача: современный лендинг YAiPlayer с анимацией и «крючками»

Сайт уже есть: `site-public/` (Vite, ванильный JS, страницы в `src/pages/`: home, download, faq, guide, legal; тексты в `src/i18n/ru|en|de.json`; цвета и бренд в `brand.json`; публикуется на Cloudflare Pages как yaiplayer.pages.dev). Нужно переделать главную (и при необходимости страницу «Скачать») в современный продающий лендинг. Кабинет пользователя живёт в другом, закрытом репозитории и здесь не трогается.

Общие правила: ветка `test/site-landing` от свежего main, в main не вливать, секреты не трогать. Тексты только через i18n-файлы на трёх языках (ru, en, de), сначала ru. Сборка `npm run build` в `site-public/` должна проходить без ошибок. Результат не деплоить: ревьюер (Claude) проверит ветку и выложит сам.

## Жёсткие ограничения (обязательно)
1. Сайт и приложение **ничего не показывают и не раздают**: везде честно «плеер не содержит каналов и контента, вы добавляете свои источники». Никаких логотипов и названий каналов, кадров из фильмов и сериалов, логотипов и названий конкурентов. На макетах экранов — только нейтральные заглушки и собственные скриншоты приложения с замазанным контентом.
2. Личной почты, имени и адреса на сайте нет (юридические страницы с незаполненными полями остаются скрытыми, как сейчас).
3. Без трекеров, аналитики и внешних скриптов; шрифты и картинки — локально или системные. Без cookie-баннера, так как cookie не ставим.
4. **Как скачать — два пути** (оба показать на главной и на странице «Скачать»):
   - **С аккаунтом (основной в будущем):** кнопка «Скачать APK» после входа в личный кабинет (регистрация без привязки почты, один аккаунт на сайте, телефоне и Android TV; синхронизация источников и избранного). Кабинет живёт в другом, закрытом репозитории и пока не готов, поэтому: в `brand.json` добавь поле `cabinetUrl` (пустое = «скоро»); пока оно пусто, карточка показывает «Личный кабинет — скоро» без ссылок и без выдуманных форм; когда адрес заполнят, кнопка «Войти / Зарегистрироваться» и «Скачать APK» заработают без правки кода. Никаких форм регистрации и ввода паролей на этом сайте не делать.
   - **Без регистрации:** ссылка на Telegram-бот выдачи `https://t.me/YAiPlayer_App_bot` (проверяет подписку на канал @YAiPlayer). Рядом ссылки на канал https://t.me/YAiPlayer и чат https://t.me/YAiPlayer_Chat. Позже приложение появится в Google Play и RuStore: оставь на странице «Скачать» блок с двумя бейджами-заглушками «Скоро в Google Play» и «Скоро в RuStore» (без логотипов этих сервисов, просто текст и нейтральная иконка), с флагами `playUrl` и `rustoreUrl` в `brand.json`.
5. Доступность: контраст, фокус с клавиатуры, `prefers-reduced-motion` отключает анимации, семантическая разметка, alt-тексты.
6. Производительность: Lighthouse (мобильный) Performance ≥ 90, Accessibility ≥ 95; без тяжёлых библиотек (только CSS-анимации, IntersectionObserver, при необходимости один лёгкий модуль).

## Структура главной
1. **Hero**: крупный заголовок («Умный IPTV-плеер для телефона и Android TV»), подзаголовок, две кнопки («Скачать в Telegram» и «Смотреть возможности»), справа анимированные макеты телефона и ТВ (CSS-анимация: плавающие карточки, переключение экранов, мерцание подсветки). Мягкий градиентный фон в фирменных цветах (`brand.json`), тёмная тема по умолчанию, переключатель светлой.
2. **Пояс доверия**: «Бесплатно, без рекламы, без аналитики, открытый код (GPL-3.0), ваши данные остаются на устройстве».
3. **Возможности** (карточки с иконками и появлением при прокрутке): Live ТВ + телепрограмма на несколько дней, архив, фильмы и сериалы, несколько EPG, M3U / Xtream / Stalker в одном приложении, быстрый старт, поиск, напоминания, мультиэкран, запись, профили.
4. **Интерактивная «примерка»**: переключатель вкладок «Телефон / Android TV» меняет макет и список функций с анимацией. Отдельный блок «Скоро»: пульт с телефона, заставка, перенос настроек.
5. **Для чего подходит**: три сценария «Подключил за минуту» (три шага: поставил, добавил источник, смотришь), с иконками.
6. **Сравнение без названий конкурентов**: таблица «YAiPlayer» против «Типичные IPTV-плееры» по пунктам (поддержка Stalker, несколько EPG, архив, без рекламы, открытый код). Только проверяемые утверждения.
7. **Отзывы/доверие**: пока реальных отзывов нет, блок «Бета: нам важна ваша обратная связь» со ссылкой на чат. Поддельные отзывы не писать.
8. **FAQ** (аккордеон): что это, откуда брать каналы (у своего провайдера), безопасно ли, что поддерживает, как обновлять, платно ли.
9. **Финальный призыв** и футер (Telegram-канал, чат, бот, гайд, GitHub).

## Раздел «Новости»
Отдельная страница `/news` и блок «Что нового» на главной (последние 3 записи). Каждая запись: версия, дата, список пунктов «что добавлено и исправлено», группы значками (🆕 новое, ✨ лучше, 🛠 исправлено). Источник: публичные GitHub Releases репозитория eai-apps/YAiPlayer. Сборка читает их скриптом в `scripts/` через публичный API без токена и сохраняет в `src/data/news.generated.json`; при недоступности сети использует закоммиченный файл. Одинаковые пункты в разных версиях не повторять. Никаких внутренних технических пунктов: берём только текст релиза как есть. RSS-лента `/news.xml` (по желанию). Для версий без заметок запись не создавать.

## Лид-магниты и «крючки» (сделать безопасными и честными)
1. **«Чек-лист: как проверить IPTV-провайдера и настроить плеер за 5 минут»** — страница с чек-листом (PDF не нужен): интерактивные галочки, сохранение прогресса в `localStorage` с `try/catch`, в конце кнопка «Скачать плеер». Полезно без подписки; ссылка на канал как «получать новости».
2. **«Подбор способа подключения»** — мини-квиз из 3 вопросов (что дал провайдер: ссылка M3U / логин-пароль / портал и MAC → показывает, какой тип источника выбрать и как заполнить форму). Только локальная логика, без отправки данных.
3. **Генератор QR для ТВ**: на странице «Скачать» QR-код ссылки на бота — отсканировал с телефона и сразу открыл. QR генерировать локально (маленькая библиотека без сети или SVG-код).
4. **Живой счётчик новостей из канала не подтягивать** (нет внешних запросов). Вместо этого блок «Последнее обновление» с версией и списком из `docs/WHATS_NEW`-данных, которые собираются на этапе сборки (`scripts/`), если это просто сделать; иначе пропусти.
5. **Анимации**: появление секций при прокрутке, плавающий макет, подсветка карточек под курсором/фокусом, плавный переход вкладок, анимированный логотип в шапке. Всё отключается при `prefers-reduced-motion`.
6. Готовые мета-теги для шеринга (Open Graph / Twitter) с красивой превью-картинкой, сгенерированной как SVG→PNG на этапе сборки или статической.

## Тесты и проверка
