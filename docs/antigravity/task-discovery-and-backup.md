# Задачи для Antigravity: «находки» и перенос настроек

Общие правила те же, что в `task-multi-epg-and-log-export.md`: репозиторий eai-apps/YAiPlayer, ветка `test/<имя>` (от свежего main, в main не вливать — это делает ревьюер), TV и телефон делаем одинаково, все тексты — через строковые ресурсы (values + values-ru + values-de), i18n-проверку литералов не ломать (`check_hardcoded_strings.py`; логи — `classify-safe --category log`), в `docs/WHATS_NEW.md` — только русские пункты для пользователя, секреты не трогать и не запрашивать. В начале каждой задачи ПРОВЕРЬ, нет ли уже частичной реализации (поиск по коду: `search`, `reminder`, `multiview`, `epg`), и расширяй существующее, а не дублируй. Уже есть и не переписывается: напоминания, мультивью, PiP, спорт, записи, таймер сна, загрузки.

Порядок: сначала A, потом B, потом C. Каждая — отдельный коммит; после каждой запускай юнит-тесты.

## Задача A. Поиск по названию передачи («где идёт Лига чемпионов сегодня?»)

Сейчас поиск ищет каналы по названию. Нужен поиск по программе телепередач.

1. В общем поиске (TV: раздел «Поиск»; телефон: поиск в гиде) добавить вкладку/секцию «Передачи»: ввод ≥ 3 символов → список программ из EPG от «идёт сейчас» и дальше (до конца хранимой программы).
2. Строка результата: название, канал (с логотипом), время начала–конца, метка «Сейчас» / «Сегодня» / «Завтра» / день недели. Сортировка: идущие сейчас, затем по времени начала.
3. Действия по нажатию: «Смотреть» (идёт сейчас → открыть канал; прошедшая с архивом → открыть из архива), «Напомнить» (существующая система напоминаний), «Записать» (существующие записи, если у канала возможна запись).
4. Запрос к БД: индекс/FTS по заголовку программы в таблице `epg_programmes` (Room-миграция, если нужно; без потери данных; не замедлять импорт EPG — индексировать при чтении, либо FTS-таблица с триггерами). Поиск без учёта регистра, с поддержкой кириллицы и ё/е.
5. Учитывать выбранный плейлист/профиль и скрытые категории: результаты только по видимым пользователю каналам. Дубли одной передачи на разных версиях канала (HD/SD) схлопнуть в одну строку.
6. Тесты: поиск кириллицы, ё/е, схлопывание дублей, фильтр скрытых каналов.

Критерий: ввожу «новости» или «футбол» — вижу, где и когда это идёт, и могу поставить напоминание в два нажатия.

## Задача B. «Сейчас в эфире» — подборки по жанрам и «Смотреть с начала»

Приманка для новых пользователей: открыл приложение и сразу видно, что смотреть, без листания 500 каналов.

1. На главном экране (TV и телефон) новая лента «Сейчас в эфире»: чипы-жанры (Фильмы, Сериалы, Спорт, Новости, Детям, Музыка, Познавательное) → горизонтальный ряд карточек: название передачи, канал, прогресс-бар (сколько уже прошло), время окончания.
2. Жанр брать из XMLTV `<category>` программы (маппинг словаря категорий на 7 чипов — русские и английские названия, без учёта регистра; в отдельном тестируемом объекте). Нет категории → попадает только в общий список «Все». Чип без передач не показывать.
3. Только каналы из видимых категорий текущего профиля; один канал — максимум одна карточка (лучшая версия).
4. На карточке и в панели управления плеера, если у канала есть архив (catchup) и передача идёт ≥ 2 минут, — кнопка «С начала»: открывает идущую передачу с её начала через существующий механизм архива. Если архива нет — кнопки нет.
5. Обновление ленты раз в минуту, без мерцания и без запросов к сети (только БД).
6. Тесты: маппинг жанров, выбор лучшей версии канала, расчёт прогресса.

Критерий: на пустом профиле после синхронизации главный экран показывает «Сейчас в эфире» с жанрами; «С начала» запускает передачу с её начала на канале с архивом.

## Задача C. Перенос настроек на новое устройство («купил новую приставку — всё уже на месте»)

Приманка: переезд за минуту, без ввода всего заново.

1. Настройки → «Резервная копия»: «Сохранить копию» и «Восстановить из копии».
2. Файл `yaiplayer-backup-YYYYMMDD.json`, версия формата в заголовке. В копию входят: профили (имя, аватар, режим быстрого старта), избранное, скрытые/закреплённые категории и каналы, пользовательские категории и порядок, сортировки, настройки интерфейса и плеера, список источников EPG. В копию НЕ входят логины, пароли, токены, MAC-адреса и полные адреса плейлистов с ключами — только название плейлиста и тип; при восстановлении пользователь заново подключает плейлист (приложение сопоставляет по названию и подставляет избранное и порядок).
3. Передача:
   - телефон: системное меню «Поделиться» / выбор файла при восстановлении;
   - TV: по домашней сети, как в экспорте журнала (`LogExportServer`): адрес + QR; для восстановления страница с кнопкой «Загрузить файл» (одноразовый токен, 5 минут, только локальная сеть, лимит размера файла 5 МБ).
4. Восстановление: сначала предпросмотр («Профилей: 2, избранных каналов: 48 …»), по подтверждению — применение; ошибочный или чужой формат — понятное сообщение, ничего не ломается; версия копии новее приложения — отказ с просьбой обновить.
5. Тесты: round-trip (сохранить → восстановить → совпадает), отсутствие секретов в файле, битый JSON, копия новее приложения.

Критерий: на втором устройстве после восстановления копии и подключения плейлиста избранное, категории и настройки совпадают с первым.
