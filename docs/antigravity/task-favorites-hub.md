# Задача: раздел «Избранное» (витрина любимых каналов по категориям)

Общие правила как в остальных заданиях в `docs/antigravity/`: ветка `test/favorites` от свежего main, в main не вливать, тексты только через строковые ресурсы (values, values-ru, values-de), i18n-проверку литералов не ломать, в `docs/WHATS_NEW.md` только русские пункты для пользователя, секреты не трогать и не запрашивать. Новый код в пакете `tv.own.owntv.extras.favoriteshub` с заголовком `// Copyright (C) 2026 YAiPlayer authors. Original code, written for YAiPlayer.`; правки существующих файлов минимальные (только подключение), список файлов в разделе «Оригинальный код YAiPlayer» в `HANDOFF.md`. ТВ и телефон делаем одинаково.

## Идея

Новая кнопка бокового меню «Избранное»: страница в стиле главной (плитки каналов), но только с каналами из избранного, сгруппированными по категориям, из которых они добавлены. Это быстрый «личный пульт» зрителя: открыл и сразу видно любимое, что идёт сейчас, и что есть в архиве. Существующий список «Избранное» внутри «Прямого эфира» остаётся без изменений.

## Где кнопка
1. **ТВ**: боковая левая панель `StageRail.kt`. Порядок сейчас: логотип, Поиск, Главная, Прямой эфир (иконка ТВ), Спорт (кубок), Телегид, Фильмы, Сериалы, Загрузки, Ещё; внизу профиль и «Пересинхронизировать». Новую кнопку «Избранное» (иконка сердца или звезды в стиле остальных) поставить **между «Прямой эфир» и «Спорт» (кубок)**, то есть сразу перед кубком, в основной группе, а не внизу. Учесть подписи и фокус пульта (D-pad), раскрытие панели, подсветку активного пункта, значок количества не нужен.
2. **Телефон**: найди навигацию мобильного приложения (`MobileShell`, нижняя панель/вкладки). Если на нижней панели есть место, добавь вкладку «Избранное» рядом с «Прямой эфир»; если мест нет, вынеси её на главный экран отдельной крупной кнопкой-плиткой и в меню «Ещё». Сохрани паритет возможностей с ТВ.

## Что на странице
1. Заголовок «Избранное», внизу плитки каналов как на главной (`Home`): логотип, название, **иконка канала обязательно показывается** (если иконки отключены для плейлиста — всё равно показывать для этой страницы, заглушка только если логотипа нет), строка «Сейчас в эфире» с названием передачи, остаток времени и полоска прогресса из EPG.
2. Группировка: ряды (на ТВ горизонтальные ряды, как «Общие», «Новостные», «Кино» на главной) по категориям плейлиста, из которых канал добавлен в избранное. Название ряда — название категории. Порядок рядов — как порядок категорий в плейлисте; внутри ряда — порядок избранного (ручной порядок, если задан, иначе по номеру канала).
3. Если избранных каналов нет, показать понятную пустую страницу: «Добавляйте каналы в избранное (удерживайте OK на канале)» и кнопку «Открыть Прямой эфир». Для телефона — подсказка «нажмите ♥ на канале».
4. **Метка архива**: на плитке, если у канала есть архив (поле `catchup` / `catchupDays` в данных канала), маленький значок часов/«Архив» в углу и подпись «Архив N дн.» (когда число дней известно). Если архива нет — метки нет. Метка должна использовать существующие поля канала и не зависеть от парсера (его правит ревьюер отдельно).
5. Действия по плитке: OK/тап — смотреть; удержание — меню как у канала в списке (убрать из избранного, архив, запись, напомнить), через существующие компоненты.
6. Работает для всех типов источников: M3U-плейлисты, Xtream и Stalker-порталы. Если подключено несколько плейлистов, показывать избранное активного плейлиста (как работает остальное приложение) и переключатель в шапке «Все плейлисты / Текущий» (если это просто сделать; иначе только текущий).
7. Каналы из скрытых категорий и закрытые родительской блокировкой не показывать.
8. Загрузка быстро: данные из БД (Room), EPG-строки только для видимых плиток; прокрутка без подтормаживаний на слабых приставках.

## Тесты
Группировка по категориям и порядок рядов, пустое состояние, скрытые категории не попадают, метка архива появляется только при наличии архива, переключение «Все плейлисты / Текущий».

## Критерий готовности
На ТВ между «Прямой эфир» и кубком есть кнопка «Избранное»; страница показывает плитки избранных каналов рядами по категориям с иконками, текущей передачей, прогрессом и меткой «Архив» там, где он есть; на телефоне то же самое.
