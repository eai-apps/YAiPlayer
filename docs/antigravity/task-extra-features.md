## 1. «Вчера в эфире» (ТВ и телефон)
На канале с архивом (catchup есть) — кнопка/пункт меню «Вчера в эфире». Открывает программу канала за прошлые дни (глубина = архивные дни канала) и по выбору передачи запускает архив существующим механизмом (CatchupUrl). Ничего нового в данных не хранить.

## 2. Таймер сна (ТВ и телефон)
В плеере: 15/30/45/60/90 минут и «После этой передачи». По истечении — остановить воспроизведение и выйти из плеера. Состояние в памяти (ViewModel), не в БД. Тест: чистая логика таймера.

## 3. Мульти-вид 2–4 канала (сначала ТВ)
Режим «Несколько каналов»: из плеера удержание OK → «Добавить в мульти-вид» → сетка 2×1 / 2×2. Звук только у выбранного окна, переключение стрелками, OK — развернуть на весь экран. Ограничение: на слабых устройствах (мало RAM) максимум 2 окна, определяй по ActivityManager.isLowRamDevice / memoryClass. Окна второго и далее — только Media3 (не mpv). Освобождай плееры при выходе. Если не получается без переписывания основного плеера — сделай минимальный прототип 2 окна и опиши ограничения.

## 4. Подготовка к ребрендингу (БЕЗ изменения поведения приложения)
Цель: «указать новое имя, цвета, логотипы, адреса GitHub/Cloudflare — и получить такую же сборку».
- Создай `docs/REBRAND.md`: полный перечень мест, где зашиты название YAiPlayer, applicationId, цвета, логотипы, ссылки (GitHub, Telegram, сайт, API), строки «О программе».
- Создай `tools/rebrand/brand.example.json` (поля: appName, applicationId, primaryColor, accentColor, githubOwner/Repo, telegramChannel, siteUrl, apiBaseUrl, logo paths) и `tools/rebrand/apply_brand.py` в режиме `--dry-run` по умолчанию: ищет и ПЕЧАТАЕТ, что заменил бы, без записи. Запись только с флагом `--apply`. Не запускай `--apply` на репозитории.
