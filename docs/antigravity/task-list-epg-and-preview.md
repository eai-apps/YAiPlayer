# Задача: телепрограмма в списке каналов + кнопка превью (ТВ + телефон)

Ветка: `test/list-epg` от свежего `main`. Прочитай `HANDOFF.md`. Сборку локально не запускай, CI проверит сам.
Правила: только существующие компоненты (перед каждым вызовом сверь сигнатуру в исходнике), новые тексты в `strings_*.xml` en/ru/де, без force-push, в отчёте только то, что реально сделано.

## Проблема
В списке «Прямой эфир» у части каналов нет строки «Программа · осталось N мин», хотя в плеере, при вызове телепрограммы и архива, у этого канала программа есть. Причина: список читает только сохранённую телепрограмму (`LiveEpgReader.nowProgrammesFor`, второй проход берёт только из кэша, в сеть не ходит), а плеер берёт ещё и «короткую» телепрограмму у провайдера (`providerProgrammes` / `nowNext`). Комментарий в `nowProgrammesFor` объясняет, почему нельзя запрашивать провайдера для всех каналов сразу (сотни запросов, список пустел). Этот запрет остаётся.

## 1. Докачка только для видимых строк
- Когда список остановился (прокрутка и фокус не менялись ~400 мс), для каналов, которые сейчас на экране (видимые строки + по 3 сверху и снизу) и у которых нет программы, вызвать `providerProgrammes` (или `nowNext`), максимум 3 запроса одновременно. Запросы отменяются, если строка ушла с экрана.
- Результат кладётся в тот же кэш, откуда `nowProgrammesFor` берёт `cachedNow`, и список обновляется.
- Если у провайдера канал не отдал ничего, не повторять запрос для этого канала в течение 10 минут (запоминать пустой результат).
- Не трогать порядок загрузки EPG, `EpgSyncWorker`, `BuiltinGuide`, `EpgRepository`.

## 2. Кнопка «Показать телепрограмму из памяти»
- В меню «Параметры» списка каналов (удержание OK на ТВ; меню списка на телефоне) пункт «Обновить программу в списке»: сбрасывает кэш пустых результатов и заново запускает п.1 для видимых строк, плюс перечитывает сохранённую телепрограмму. Без сети для остальных каналов.

## 3. Превью: включить/выключить там же, где пересинхронизация
- Рядом с пунктами «Синхронизация» / «Перезагрузить портал» (боковая панель ТВ, настройки портала, телефон там же) добавить переключатель «Превью каналов». Использовать ТОТ ЖЕ параметр, что и переключатель превью в быстрых действиях (task-quick-actions.md); новый параметр не заводить. Выключено: в правой панели вместо видео только логотип и название канала, плеер превью не запускается.

## 4. Тормоза при выходе из плеера в меню (только собрать данные, не лечить вслепую)
После просмотра на весь экран и архива «Назад» зависает на ~5 с, чёрный экран, иногда выкидывает на главную. Добавь в лог (в существующий `CorePerf.log` / журнал приложения, без новых зависимостей) метки времени: нажатие «Назад» в плеере, остановка каждого плеера (Exo и mpv), закрытие архива, первая отрисовка списка, пересборка `nowProgrammesFor`, запуск превью. Если нашёл очевидную причину (например, превью стартует до того, как остановлен полноэкранный плеер, или список пересобирается много раз подряд), исправь её отдельным коммитом и опиши в отчёте. Если очевидного нет, не гадай.
