# Задание: «Ускорь телевизор» — интерфейс мастера (только телефон)

Ветка: `test/tv-optimizer-ui` от свежего main. Только приложение для ТЕЛЕФОНА. Правила как всегда: строки через i18n (en/ru/de) + ratchet в `clients/owntv-core/tools/i18n/`; код в `tv.own.owntv.extras.tvoptimizer.*` с заголовком авторства; тесты настоящие; API сверяй по коду; не трогай EPG, БД-миграции, синхронизацию.

Идея и источник: docs/CHECKLIST.md раздел 6ж (по мотивам Gathin23/cleanyourtv, MIT — лицензию и авторство сохранить в «О программе» → «Лицензии»). РЕАЛЬНАЯ работа с ADB делается позже (Opus). Твоя часть — весь интерфейс и логика мастера поверх интерфейса-заглушки.

## 1. Место на стартовом экране телефона
Ряд на экране выбора профиля: [главный профиль (аккаунт) + дополнительные профили] · [Гость] · [Пульт ДУ] · [Ускорь телевизор]. Кнопка «Ускорь телевизор» рядом с «Пульт ДУ», та же визуальная система. Использовать существующую кнопку «Пульт» как образец.

## 2. Мастер (экраны по шагам, кнопки «Назад/Далее», прогресс)
1. Предупреждение: «Вы делаете это на свой страх и риск». Крупно, чекбокс «Я понимаю» обязателен. Текст: приложения только ОТКЛЮЧАЮТСЯ (не удаляются), всё можно откатить, но прошивка может вернуть изменения, перед работой сохраняется состояние.
2. Включение отладки на ТВ (пошагово, с картинками-подсказками из векторных иконок): Настройки → О устройстве (или «Об устройстве») → 7 раз нажать «Номер сборки» → вернуться → Для разработчиков → включить «Отладка по USB» и «Отладка по сети»/«Отладка по Wi-Fi» → запомнить IP ТВ. Варианты для разных производителей (Android TV, Xiaomi, Sony, TCL, Philips, Google TV Streamer) в сворачиваемых блоках. Кнопка «Не нашёл» → короткая подсказка.
3. Подключение: найти ТВ в сети (используй уже существующий механизм поиска приёмника пульта) или ввод IP:порт вручную (по умолчанию 5555). Статус: ищем / подключено / ТВ запросил разрешение — «Нажмите «Разрешить» на экране ТВ».
4. Выбор модели: автоопределение (заглушка) + ручной список с поиском.
5. Список «что отключим»: пакеты с понятным пояснением («Что это» / «Можно ли отключать»), галочки, значок осторожности у системных, «Выбрать рекомендуемое». Данные берутся из интерфейса `TvOptimizerRepository` (см. ниже).
6. Подтверждение + «Сохранить состояние перед применением» (обязательный шаг).
7. Результат: что отключено, сколько памяти освободилось (если заглушка не знает — не показывать), кнопка «Откатить всё».
8. Экран «Откат»: список изменений и кнопка отката выбранных/всех.

## 3. Архитектура
- `interface AdbTransport { connect(host, port); runShell(cmd): Result; disconnect() }` — реализация-ЗАГЛУШКА `FakeAdbTransport` (имитация, чтобы мастер работал в демо). Настоящую реализацию НЕ писать.
- `interface TvOptimizerRepository { models(); packagesFor(model); }` с демо-данными в assets/tvoptimizer/demo.json (5–8 условных пакетов). Формат JSON описать в `docs/TV_OPTIMIZER_DATA.md` (поля: package, titleKey, descriptionKey, risk, recommended).
- Состояние мастера — ViewModel + sealed class шагов; бэкап/откат — сохранение списка изменённых пакетов в DataStore (без БД).
- Тесты: переходы шагов, обязательность чекбокса, формирование команды (`pm disable-user --user 0 <pkg>` и обратная `pm enable <pkg>`) как чистая функция.

## Не делать
Реальный ADB, загрузку списков из сети, установку лаунчера, любые изменения ТВ-приложения.
