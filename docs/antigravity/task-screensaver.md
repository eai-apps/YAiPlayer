# Задача: экранная заставка («Заставка») для ТВ

Общие правила как в `task-multi-epg-and-log-export.md` и `task-phone-remote.md`: ветка `test/screensaver` от свежего main, в main не вливать, тексты через строковые ресурсы (values, values-ru, values-de), i18n-проверку литералов не ломать, в `docs/WHATS_NEW.md` только русские пункты для пользователя, секреты не трогать. Новый код в отдельном пакете `tv.own.owntv.extras.screensaver` с заголовком `// Copyright (C) 2026 YAiPlayer authors. Original code, written for YAiPlayer.`, минимальные правки существующих файлов (только точки подключения), список файлов в разделе «Оригинальный код YAiPlayer» в `HANDOFF.md`. Любой внешний контент или код — только с записью источника и лицензии в `docs/THIRD_PARTY.md`.

## Идея

Если приложение на ТВ открыто, но ничего не происходит, включается красивая заставка (как в приложении «Лампа»): плавные фото природы и космоса, постеры из каталога пользователя, часы. Любая кнопка пульта закрывает её. Заодно это защита экрана от выгорания, когда на паузе или завис канал.

## Когда включается
1. Нет нажатий кнопок дольше выбранного времени (по умолчанию 5 минут) И выполняется одно из:
   - ничего не воспроизводится (меню, списки, настройки);
   - воспроизведение на паузе;
   - канал завис: плеер в состоянии буферизации/остановки без прогресса дольше выбранного времени.
2. Не включается, пока что-то реально играет и идёт картинка (кино, канал). Не включается во время записи на экране записей, при открытом диалоге ввода PIN и при активном экранном вводе текста.
3. Любая кнопка пульта закрывает заставку, и это нажатие не передаётся дальше (не нажимает OK на скрытом элементе). После закрытия возвращается тот же экран.
4. Если на паузе и заставка закрыта нажатием «Play», воспроизведение продолжается.

## Что показывает (режимы, настройка)
Настройки → Заставка: переключатель, время до включения (1 / 3 / 5 / 10 / 15 / 30 минут), режим, «Показывать часы» (вкл/выкл), «Предпросмотр».
Режимы:
1. **Постеры каталога**: плавная смена обложек фильмов и сериалов из выбранного плейлиста (эффект Ken Burns: медленный наезд и плавное затухание), внизу название и жанр. Работает без интернета. Скрытые и «взрослые» категории не показывать, учитывать родительскую блокировку профиля.
2. **Природа и космос (фото)**: подборка красивых фото высокого качества с плавной сменой.
3. **Часы**: крупные часы и дата, медленно смещаются по экрану (против выгорания), тёмный фон.
4. **Микс**: постеры, природа и часы по очереди.
5. (Опционально, второй этап) **Видео-фон**: тихое зацикленное видео (камин, дождь, море, космос) через Media3, без звука, только по Wi-Fi, кэш не более 200 МБ, при ошибке откат на фото.

Часы поверх фото (небольшие, в углу, со смещением раз в минуту) включаются отдельным переключателем.

## Источники контента
1. Фото и видео брать ТОЛЬКО из источников с лицензией CC0/Public Domain или явным разрешением на свободное использование (например, Wikimedia Commons CC0, NASA, Unsplash/Pexels по их лицензии, если она разрешает такое использование). В APK много не класть (ограничение прироста размера ≤ 5 МБ): небольшой встроенный набор для работы без сети, остальное подгружается.
2. Манифест `screensaver.json` (список адресов, подписи и лицензия каждого файла) лежит на нашем хостинге; приложение раз в неделю его обновляет и кэширует изображения на диск (Coil disk cache, ≤ 150 МБ). Нет сети → встроенный набор и постеры каталога.
3. Каждый элемент манифеста: `url`, `type` (photo/video), `license`, `source`, `title`. Список источников и лицензий записать в `docs/THIRD_PARTY.md`.

## Требования к качеству и нагрузке
1. Слабые приставки: анимации через Compose `graphicsLayer`, без пересборки больших деревьев; картинки не больше 1080p; без утечек памяти (освобождать Bitmap при закрытии).
2. Во время заставки сетевые синхронизации не прерывать; воспроизведение не запускать; звук не включать.
3. Яркость: фон тёмный, переходы плавные (кроссфейд 1,5 с), смена кадра каждые 12 с (настройка не нужна).
4. Управление с пульта: только закрытие заставки любой кнопкой.
5. Тесты: логика таймера простоя (сброс по нажатию, не включаться при воспроизведении, включаться на паузе и при зависшем канале), выбор элементов (скрытые категории не попадают), разбор манифеста.

## Этап 2 (после основного): системная заставка Android TV
Реализовать `DreamService` (Daydream), чтобы заставку можно было выбрать в системных настройках Android TV: Настройки → Устройство → Заставка. Использует те же режимы. Если платформа/прошивка не поддерживает, пропустить без ошибок.

## Критерий готовности
Оставляю приложение в меню на 5 минут: включается плавная заставка с постерами, нажатие любой кнопки возвращает экран. Ставлю фильм на паузу на 5 минут: включается заставка; «Play» продолжает фильм. Пока играет канал, заставки нет.
