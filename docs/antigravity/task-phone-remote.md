# Задача: телефон как пульт для ТВ («Пульт»)

Общие правила как в `task-multi-epg-and-log-export.md`: ветка `test/remote` от свежего main, в main не вливать, тексты только через строковые ресурсы (values, values-ru, values-de), i18n-проверку литералов не ломать, в `docs/WHATS_NEW.md` только русские пункты для пользователя, секреты не трогать и не запрашивать. Перед началом проверь, что уже есть в коде (поиск `LogExportServer`, `NsdManager`, `multiview`, `reminder`), и переиспользуй, а не дублируй.

## Идея

На телефоне появляется раздел «Пульт»: управляет приставкой по домашней Wi-Fi без регистрации. Два уровня:

1. **Пульт YAiPlayer** (свой протокол, этап 1, главное). Управляет нашим приложением на ТВ: каналы, воспроизведение, поиск, «Отправить на ТВ».
2. **Пульт всего Android TV** (этап 2, по желанию). Кнопки системы, ввод текста и запуск других приложений через штатный протокол Android TV Remote v2 (порты 6467 для сопряжения и 6466 для команд, TLS + protobuf, тот же протокол, что в приложении Google TV). Справочные реализации с открытым кодом: louis49/androidtv-remote (Node, MIT), tronikos/androidtvremote2 (Python), описание протокола в вики Aymkdn/assistant-freebox-cloud. Лицензии проверь сам, код копировать только совместимый с GPL-3.0, иначе писать заново по описанию протокола. Кодирование protobuf через protobuf-javalite.

Только телефон (Android) управляет. Приёмник в ТВ-приложении работает только когда включён в ТВ: Настройки → Пульт с телефона (по умолчанию выключен).

## Этап 1. Пульт YAiPlayer

### Приёмник на ТВ
1. Маленький HTTP/WebSocket-сервер на случайном порту, TLS с самоподписанным сертификатом. Только локальная сеть, слушает, пока включён переключатель.
2. Обнаружение: NSD/mDNS, сервис `_yaiplayer._tcp`, в имени — название устройства.
3. Сопряжение: телефон выбирает ТВ из списка, на ТВ появляется 6-значный код (на 2 минуты), пользователь вводит его на телефоне. После успеха ТВ выдаёт телефону долгоживущий токен; отпечаток сертификата ТВ телефон запоминает (pinning). Ограничение попыток ввода кода (5 неудач — блок на 5 минут).
4. В ТВ: Настройки → Пульт с телефона: переключатель, список сопряжённых телефонов с кнопкой «Забыть», показ кода сопряжения.
5. Токены хранить в EncryptedSharedPreferences/Keystore.

### Команды (JSON по WebSocket)
- Навигация: вверх, вниз, влево, вправо, OK, Назад, Домой, Меню.
- Воспроизведение: пауза/плей, перемотка ±10 с и ±60 с, громкость +/− и mute (громкость приложения и системы через AudioManager), следующий/предыдущий канал, цифровой набор номера канала, «К эфиру», «Архив».
- Текст: поле на телефоне → вставка в активное текстовое поле приложения на ТВ (поиск). Голосовой ввод через микрофон телефона (системная диктовка), результат уходит как текст.
- Состояние (ТВ → телефон): что играет сейчас (название, канал/фильм, прогресс), на паузе или нет, громкость. Телефон показывает мини-плеер с этими данными.
- «Отправить на ТВ»: из карточки канала/фильма/серии и из плеера на телефоне. Телефон шлёт ссылку на объект (источник + идентификатор), если у ТВ тот же плейлист; если нет — прямой адрес потока по защищённому каналу. ТВ открывает и играет. Обратное: «Забрать на телефон» с той же позиции.
- Список избранного и недавних с ТВ: тап на телефоне → играет на ТВ.

### Экран «Пульт» на телефоне
- Расположение (главное): на экране, который телефон показывает при запуске приложения (выбор профиля / гостевой режим / вход в профиль с синхронизацией), рядом с ними крупная кнопка-значок «Пульт для вашей приставки». Она открывает пульт сразу, без выбора профиля и без регистрации. Дополнительно: иконка «Пульт» в верхней панели главного экрана и пункт в меню; в плеере кнопка «На ТВ». Найди в коде мобильного приложения экран выбора профиля (`MobileShell`, `ProfileLaunchGate`, profiles) и встрой кнопку туда.
- Сверху выбор устройства (несколько ТВ), статус подключения.
- Режимы: кнопочный пульт (D-pad, OK, Назад, Домой, громкость, каналы, цифры) и тачпад (свайп = стрелки, тап = OK); переключатель сверху.
- Физические кнопки громкости телефона управляют громкостью ТВ, пока открыт экран «Пульт» (с переключателем в настройках).
- Вибрация при нажатии (настройка).
- Постоянная карточка-пульт в шторке уведомлений (пауза, громкость, канал +/−), пока подключён ТВ и что-то играет.
- Мини-плеер и ближайший будущий шаг: под кнопками «Сейчас играет» с прогрессом.
- Нет сети / ТВ выключен: понятное сообщение и кнопка «Повторить»; автопереподключение.

### Подготовка к платному режиму (пока всё бесплатно)
- Интерфейс `RemoteEntitlement { fun canUseRemote(): Boolean }` с реализацией «всегда true»; все входы в «Пульт» через него. Никаких аккаунтов и сети наружу. Гостевой режим: пульт работает без профиля и без регистрации.

## Этап 2. Пульт всего Android TV (после этапа 1)
1. На экране «Пульт» вкладка «Система»: поиск ТВ по mDNS `_androidtvremote2._tcp`, сопряжение кодом, показанным на экране ТВ (штатный диалог системы), сертификат клиента хранить в Keystore.
2. Команды: стрелки, OK, Назад, Домой, Меню, громкость, mute, питание, медиа-клавиши, ввод текста, запуск приложений по ссылке/ярлыку.
3. Если ТВ не поддерживает протокол (старый Android TV) — понятное сообщение, этап 1 работает независимо.

## Тесты
Сопряжение (верный/неверный код, блокировка после 5 попыток), токен и pinning, сериализация команд, разбор состояния, отсутствие секретов в логах.

## Критерий готовности
Телефон находит ТВ в той же Wi-Fi, сопрягается кодом, переключает каналы, ставит на паузу, вводит текст в поиск и по кнопке «Отправить на ТВ» запускает канал на экране ТВ. Без регистрации и без интернета.

## Структура кода и лицензия (обязательно для этой и всех новых «находок»)

Приложение построено на GPL-3.0 коде OwnTV. Всё, что мы пишем с нуля, — наша собственная разработка, и мы хотим иметь возможность использовать её в других своих приложениях. Поэтому:
1. Новый код кладём в отдельные пакеты/модули: пульт — `tv.own.owntv.extras.remote` (core) и отдельные файлы `…/remote/…` в TV и телефоне; не переписываем и не смешиваем с существующими файлами OwnTV больше, чем нужно для подключения (точки входа — минимальные правки).
2. В каждом новом файле заголовок: `// Copyright (C) 2026 YAiPlayer authors. Original code, written for YAiPlayer.` и никакого кода, скопированного из внешних проектов, без указания источника и лицензии в `docs/THIRD_PARTY.md`.
3. Модули пульта не зависят от внутренностей OwnTV (БД, Koin-модули, UI-тема) там, где этого можно избежать: общие интерфейсы (`RemoteTransport`, `RemoteCommand`, `PairingStore`) в отдельном пакете, реализации под приложение — рядом. Так их позже можно вынести в общую библиотеку.
4. В `HANDOFF.md` добавь раздел «Оригинальный код YAiPlayer» со списком пакетов и файлов, написанных с нуля, и обновляй его.
