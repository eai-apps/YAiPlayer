# Задание: «Лёгкий режим» для слабых приставок (ТВ и телефон)

Ветка: `test/light-mode` от свежего main. Правила как всегда: i18n en/ru/de + ratchet `clients/owntv-core/tools/i18n/`; новый код в `tv.own.owntv.extras.*` с заголовком авторства; тесты настоящие; API сверять по коду; не трогать EPG-ядро, миграции БД, синхронизацию, плеер.

## Что сделать
Одна настройка «Лёгкий режим» (DataStore, по умолчанию выключена), которая одним переключателем делает то же, что уже умеют существующие настройки:
- выключает «Воспроизводить видео в главном ряду» (settings_hero_preview) и «Предпросмотр эфира» (settings_live_preview) — НЕ меняя их сохранённые значения: при выключении лёгкого режима прежние значения возвращаются;
- в списке каналов и на Главной вместо видео-превью показывается логотип канала и название текущей передачи;
- отключает необязательные анимации (если есть общая настройка анимаций — использовать её, новых не плодить).

## Где показать
1. Кнопка-переключатель в быстрых действиях рядом с «Обновить плейлист» (ТВ — боковое меню/быстрые действия; телефон — меню профиля) и в настройках в разделе «Плеер/Производительность».
2. При первом запуске на слабом устройстве (`ActivityManager.isLowRamDevice()` или memoryClass ≤ 192) один раз показать диалог «Включить лёгкий режим? Меню будет быстрее на этом устройстве» с кнопками «Включить» / «Не сейчас» (запомнить выбор).

## Тесты
Чистая логика: effective(heroPreview, livePreview, lightMode) → значения; восстановление прежних значений; решение о показе диалога по памяти и по сохранённому выбору.
