## 2. Data Processed Currently

### 2.1. Website Access & Server Logs
When accessing this website, the visitor's web browser automatically transmits technical connection metadata recorded in CDN and server infrastructure logs:
- IP address of the accessing client (anonymized or truncated where supported);
- Date and exact timestamp of request;
- Requested resource URL and transferred payload size;
- Browser software type, version, and operating system;
- HTTP Referrer header;
- HTTP status code returned.

**Purpose**: Maintaining availability, monitoring operational integrity, and mitigating network attacks (e.g. DDoS).
**Legal Basis**: Art. 6(1)(f) GDPR (legitimate interest in secure and resilient service delivery).

### 2.2. Hosting & Content Delivery Network (Cloudflare)
This website is hosted on **Cloudflare Pages** (provided by Cloudflare, Inc., 101 Townsend St, San Francisco, CA 94107, USA).
Cloudflare operates as a reverse proxy, content delivery network (CDN), and security barrier. Web traffic routes through Cloudflare's global edge infrastructure. For cross-border transfers from the EU, Cloudflare relies on Standard Contractual Clauses (SCCs).

### 2.3. Cookies and Tracking
This website **does not use** tracking, analytics, or behavioral advertising cookies. Strictly necessary security tokens may be issued by the CDN layer to mitigate automated abuse.
