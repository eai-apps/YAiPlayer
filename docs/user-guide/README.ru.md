## 1. О приложении YAiPlayer

**YAiPlayer** — это современный медиаплеер для воспроизведения IPTV на телевизорах с Android TV и мобильных устройствах под управлением Android.

> [!IMPORTANT]
> **YAiPlayer не содержит встроенных каналов, фильмов, плейлистов или подписок.**
> Приложение является исключительно плеером. Для просмотра вам необходим собственный легальный источник: ссылка на плейлист (M3U), данные доступа к серверу Xtream Codes или порталу Stalker/Ministra, предоставленные вашим поставщиком услуг.

## 2. Установка и обновления

### Установка приложения
1. Откройте страницу релизов проекта на GitHub (`https://github.com/eai-apps/YAiPlayer/releases`).
2. Скачайте актуальный файл `.apk` для вашего типа устройства (версию для Android TV или версию для смартфона).
3. При первой установке разрешите операционной системе установку приложений из внешних источников (неизвестных источников).
4. Запустите загруженный файл и подтвердите установку.

### Проверка и получение обновлений
Приложение умеет проверять наличие новых версий напрямую:
- Перейдите в **«Настройки»** (или нажмите значок шестерёнки в меню плейлистов).
- Выберите раздел **«О приложении»**.
- Нажмите кнопку **«Проверить обновления»**.
- Если доступна новая версия, приложение предложит скачать и установить её.

## 3. Добавление источника

Чтобы начать просмотр, необходимо подключить хотя бы один источник контента:

### M3U-ссылка или файл
- В окне добавления источника выберите **«M3U-ссылка или файл»**.
- Введите URL-адрес плейлиста (например, `http://example.com/playlist.m3u8`) либо выберите локальный файл на устройстве.
- При необходимости укажите отдельную ссылку на телегид (XMLTV EPG).

### Xtream Codes API
- Выберите вариант **«Xtream Codes»**.
- Заполните поля:
  - **Адрес сервера**: URL провайдера (с указанием порта, если требуется).
  - **Имя пользователя** (логин).
  - **Пароль**.
- Нажмите «Подключить» — приложение автоматически загрузит категории каналов, фильмов и сериалов.

### Stalker / Ministra портал
- Выберите **«Stalker (MAC)»**.
- Заполните поля:
  - **Адрес портала**: URL портала Stalker (обычно заканчивается на `/c/`).
  - **MAC-адрес**: шестнадцатеричный идентификатор в формате `00:1A:79:XX:XX:XX`.
  - **Логин и пароль**: заполняются только в том случае, если ваш провайдер требует авторизацию поверх привязки к MAC-адресу.

> [!NOTE]
> **Откуда взять MAC-адрес?**
> MAC-адрес для Stalker-портала назначается вашим провайдером при оформлении подписки либо регистрируется вами в личном кабинете провайдера. Приложение позволяет использовать существующий MAC или сгенерировать совместимый адрес виртуальной приставки.

## 4. Прямой эфир (Live TV)

В разделе **«Прямой эфир»** доступны два режима отображения:
- **«Список каналов»** — компактный список с группами категорий слева и быстрым предпросмотром выбранного канала.
- **«Телегид» (EPG)** — сетка программы передач по времени, позволяющая видеть, что идёт сейчас и какие передачи планируются далее.

### Переключение режимов
- Нажмите кнопку переключателя **«Список / Телегид»** в верхней панели или в меню управления экраном.
- В меню **«Настройки» → «Прямой эфир»** можно настроить поведение по умолчанию: например, открывать прямой эфир сразу в виде сетки телегида или в виде списка каналов.
- Доступна настройка ширины столбцов (список каналов / шкала времени) и часового пояса программы передач.

## 5. Главная страница и настройка рядов

Главный экран собирает ключевые элементы для быстрого доступа:
- **«Категории каналов»** — тематические подборки каналов прямо на главной (до 8 категорий по 20 каналов).
- **«Все каналы»** — быстрый доступ к первым 30 каналам из ваших активных плейлистов.
- **«Недавно добавленные фильмы»** — свежие поступления в фильмотеку (до 30 новинок).
- **«В эфире»** / **«Недавние каналы»** и **«Избранные каналы»** — каналы, которые вы часто или недавно смотрели.
- **«Продолжить просмотр»** — фильмы и серии, воспроизведение которых было приостановлено.

### Как настроить главную страницу
1. Откройте **«Настройки» → «Главная»**.
2. Включайте или отключайте отображение конкретных рядов.
3. Меняйте порядок рядов с помощью кнопок перемещения, чтобы расположить наиболее нужные блоки сверху.

## 6. Устранение неполадок

### Если каналы не появились или синхронизация завершилась с ошибкой:
1. Проверьте правильность введённого адреса, логина и пароля.
2. Убедитесь, что устройство подключено к интернету и сервер провайдера доступен.
3. Откройте **«Настройки» → «Плейлисты»**, выберите проблемный источник и нажмите **«Синхронизировать заново»**.

### Если не работает Stalker-портал:
1. Убедитесь, что провайдер активировал подписку именно для введённого MAC-адреса.
2. В карточке источника выберите пункт **«Очистить данные Stalker (сессия и список каналов)»**, после чего повторите вход. Это сбросит устаревший токен сессии и кешированные списки.
3. Если портал использует проверку модели приставки, перейдите в расширенные настройки Stalker в карточке источника и проверьте параметр User-Agent (например, выберите профиль MAG250).

---

## 7. Приватность и безопасность

- **Прямое соединение**: YAiPlayer подключается напрямую к серверам вашего провайдера IPTV и EPG.
- **Без сторонней телеметрии**: приложение не собирает персональные данные, не содержит рекламных модулей и не отправляет логи на сторонние аналитические платформы.
- **Локальное хранение**: пароли, токены и списки избранного хранятся локально на вашем устройстве в защищённом хранилище приложения.
- **Резервные копии**: при создании резервной копии настроек обращайте внимание на параметры шифрования, если вы планируете передавать файл бэкапа на другие устройства.
