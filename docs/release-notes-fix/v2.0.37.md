- Встроенная программа передач: каналы сопоставляются по названию автоматически, источники обновляются по очереди; в настройках у каждого источника есть кнопка «обновить» и число каналов с программой.
- Закрытие плеера крестиком в шторке теперь действительно останавливает воспроизведение и убирает уведомление (и для фильма, и для канала).
- «О приложении»: убрана ссылка на GitHub. Вверху главной — логотип, название и версия приложения.
- Главная на телефоне: у канала без логотипа в плитке показывается номер.
