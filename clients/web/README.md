# YAiPlayer Web Client

Адаптированный веб-клиент YAiPlayer на базе StreamVault UI, подключенный к общему Worker API YAiPlayer.

## Назначение
- Полнофункциональный браузерный IPTV плеер (Xtream Codes, M3U/M3U8 плейлисты и локальные файлы, Stalker Portal, прямые HLS потоки).
- Авторизация учетной записи YAiPlayer (логин/пароль) и синхронизация облачного реестра источников.
- Компаньон привязки TV-устройств (`/pair`) для ввода 6-значного PIN-кода с экрана телевизора.
- Информационный раздел с указанием статусов релизов Android TV/Mobile и открытыми правовыми уведомлениями.
